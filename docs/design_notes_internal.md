# 内部設計メモ（配布物ではない / not shipped in README）

このファイルは実装判断の記録である。README・公開ページには載せない。

## 2. 意図的に採らなかったもの

- **自動書き換え**: 自然言語の自動置換は誤爆時に意味を壊す。指摘 + AS-IS/TO-BE 例までにする。
- **LLM 判定**: フックが API キーとネットワークを要求すると外される。全て正規表現で完結させる。
- **英語規則**: 既存の英語向けツールが充実しているため対象外。差別化の焦点をぼかさない。
- **出典のない規則**: 体感で作った規則は入れない。指標として出すか、捨てる。

- 文化審議会建議・JTF スタイルガイド: 規則番号と短い引用のみ。全文は再配布しない。
- textlint-ja 各規則: 名称と既定値の参照のみ。実装は独自。
- 参照した外部スキル: 実装・文言の複製なし。設計の確認のみ。README にも記載しない。
