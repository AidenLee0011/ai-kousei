nativecommit — commit messages that read like a person wrote them, in your language

Deterministic linter. No model call, no network. Japanese, Korean, Chinese, German, French, Spanish. English is out of scope by design.

    Rules are plain JSON. One file per language, loaded by both the CLI and this page, so the demo and the hook can never drift apart.
    
    
    

    
    
      
    use it on your repository
    
      pip install nativecommit
natc hook install --lang ja
git commit          # a generated-looking message is rejected before it lands
      
    The hook exits non-zero on any error level finding. Warnings are printed and let through. Merge, squash and fixup messages are skipped.
    
      natc lint .git/COMMIT_EDITMSG
natc lint -m "fix: 各種修正" --lang ja --json
natc template --lang ko --pr
      
    Every finding carries the reason and the rewrite in the language being linted, not in English.
